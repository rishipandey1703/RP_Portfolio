# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/rishipandey1703/RP_Portfolio.git
```

Move into the project

```bash
cd RP_Portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
